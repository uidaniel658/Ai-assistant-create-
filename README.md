# ALTREX CODE

ALTREX CODE is a next-generation AI software engineering platform concept UI. It presents an AI coding agent, multi-agent swarm system, AI IDE, app builder, website builder, testing platform, auto-debugger, build system, APK/AAB generator, Git platform, deployment platform, and AI engineering team.

## Golden Rule

ALTREX never fakes success. Build, test, APK, security, and release states must be reported as `VERIFIED`, `UNVERIFIED`, or `FAILED` based on real execution.

## Core Loop

UNDERSTAND → PLAN → DELEGATE → IMPLEMENT → EXECUTE → TEST → DEBUG → REVIEW → VERIFY → BUILD → PACKAGE → DOWNLOAD → DEPLOY
